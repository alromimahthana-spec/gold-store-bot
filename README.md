# Gold Store Bot 💍 | بوت متجر الذهب والمجوهرات
بوت تلجرام ذكي لأصحاب محلات الذهب في السعودية واليمن ✨

يبيع لك وانت نايم، ويرد على الزباين، ويحسب الأسعار تلقائياً.

## ✨ وش يسوي البوت للزبونة؟
- 💍 يعرض أطقم الذهب والمجوهرات بالصور والأسعار
- 💰 يحسب سعر الذهب بالجرام + المصنعية بشكل تلقائي
- 📅 يحجز الطقم للزبونة بدون ما تكلمك
- 🔥 يعرض عروض اليوم وآخر التخفيضات
- 📦 ياخذ طلب الزبونة ويرسله لك على طول

## 👑 وش يسوي البوت لصاحب المحل؟
- يرد على الزباين 24 ساعة، حتى وانت نايم
- يوفر عليك موظف يرد على الرسائل
- يرتب لك الطلبات والحجوزات
- يزيد مبيعاتك لأنه ما يخلي أي زبونة تنتظر

## 🛠️ مصنوع بـ
- Python
- Telegram Bot API

## 🚀 كيف تشغله؟
1. ثبّت المكتبات:
   pip install -r requirements.txt
2. حط التوكن حقك في ملف .env
3. شغل البوت:
   python main.py
